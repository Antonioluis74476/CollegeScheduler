College Scheduler
Overview

The College Scheduler is a full-stack web application designed to manage academic timetables, room allocation, and scheduling workflows within a college environment.

The system replaces manual scheduling methods such as spreadsheets and static documents with a structured and centralized platform that improves accuracy, efficiency and visibility.

It aims to:

Prevent timetable conflicts
Automate scheduling processes
Support multiple user roles
Provide real-time updates and notifications
Project Value

This system improves scheduling efficiency by eliminating manual processes and reducing human error. It provides a centralized solution where administrators, lecturers, and students can interact with timetable data in a controlled and consistent way.

The project demonstrates the practical application of modern software engineering concepts such as API-driven design, role-based access control, and scalable system architecture.

System Flow
Admin creates timetable events or recurring schedules
The system validates inputs and checks for clashes
Events are stored in the database
Lecturers and students retrieve their timetables through the API
Users submit requests such as rescheduling or room bookings
Requests go through an approval process
Notifications are generated and delivered to users

This workflow ensures data consistency, prevents conflicts and supports controlled scheduling operations.

Architecture

The project follows Clean Architecture principles to ensure separation of concerns, maintainability and scalability.

Presentation Layer → Blazor Server UI
Application Layer → Business logic and services
Domain Layer → Core entities and rules
Infrastructure Layer → Database access and external integrations

The backend is designed as an API-first system, meaning all functionality is exposed through REST endpoints and tested independently before frontend integration.

This structure allows different parts of the system to evolve independently and supports future expansion.

Technology Roles

SignalR: 
Enables real-time notifications when timetable changes or request updates occur.

RabbitMQ: 
Enables asynchronous communication between components, supporting scalability and decoupled system design.

Swagger:
Allows testing and validation of API endpoints independently of the frontend.

CloudAMQP:
Provides a managed cloud-hosted RabbitMQ instance used for queueing and background message processing.
Cloud queueing is hosted at:
https://ostrich.lmq.cloudamqp.com/
Access can be provided if required for assessment or demonstration purposes.

Mailtrap:
Provides a secure email testing environment by intercepting all outgoing SMTP emails generated by the application.
Instead of delivering messages to actual recipients, Mailtrap captures them in a dedicated inbox, 
allowing the email workflow, content, and delivery process to be verified under realistic conditions.
Mailtrap is available at:
https://mailtrap.io/
Access can be provided if required for assessment or demonstration purposes.

Conclusion

The College Scheduler demonstrates a modern, full-stack approach to solving complex academic scheduling challenges through a scalable and maintainable software architecture. By combining Clean Architecture, ASP.NET Core, Blazor Server, Entity Framework Core, and role-based authentication, the application provides a secure and reliable platform for managing timetables, room allocations, and scheduling workflows.

Beyond traditional CRUD functionality, the system incorporates several enterprise-level technologies to improve performance and user experience. SignalR delivers real-time notifications, allowing administrators, lecturers, and students to receive immediate updates whenever timetable events or request statuses change. RabbitMQ, integrated through MassTransit and hosted on CloudAMQP, enables asynchronous messaging and queue-based processing, decoupling background operations from the main application and improving scalability, responsiveness, and reliability.

The project also implements a complete email notification pipeline using Mailtrap, which captures outgoing SMTP emails in a secure testing environment. This allows the entire email workflow—from notification generation and queue processing to message delivery—to be demonstrated and verified under realistic conditions without sending emails to real recipients.

Overall, the College Scheduler reflects real-world software engineering practices by integrating layered architecture, RESTful APIs, real-time communication, asynchronous messaging, cloud-hosted queueing, secure authentication, and email processing into a cohesive application. The resulting system is robust, extensible, and production-oriented, providing a strong foundation for future enhancements while demonstrating the practical application of modern enterprise software development principles.
